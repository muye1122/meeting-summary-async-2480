> 说明：本次为纯文档选型研究，未安装新软件、未执行基准测试。证据类型均为**官方文档事实**，而非实测性能数据；涉及"能力有无"的结论以官方功能描述为据，涉及"优劣判断"的结论为基于这些事实的工程推断。

## R2 — PostgreSQL 16 文档：WITH Queries (Common Table Expressions)

- 链接：https://www.postgresql.org/docs/16/queries-with.html
- 关键原文："Using `RECURSIVE`, a `WITH` query can refer to its own output."；7.8.2.1 Search Order（`SEARCH DEPTH FIRST / BREADTH FIRST`）；7.8.2.2 Cycle Detection（`CYCLE id SET is_cycle USING path`）；官方示例直接使用名为 `graph` 的表做递归遍历。
