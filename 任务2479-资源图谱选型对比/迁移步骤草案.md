# 一期数据迁移步骤草案（目标：推荐方案 A）

目标：把完整版资源图谱的一期数据迁入**方案 A（PostgreSQL 16 关系表 `nodes`/`edges` + 递归 CTE）**。以下为草案，所有示例表结构、字段名与数值均为虚构占位，不含任何客户信息。每步附官方文档依据。

---

## 步骤 1 — 资源盘点与图模型定稿

- 列出现有资源节点类型（如 `person`、`doc`、`project`、`service`）与关系类型（如 `owns`、`references`、`depends_on`）。
- 确定两表结构（虚构）：
  - `nodes(id bigserial PRIMARY KEY, type text, props jsonb)`
  - `edges(id bigserial PRIMARY KEY, src bigint, dst bigint, type text, props jsonb)`
- 约定 `src`/`dst` 外键指向 `nodes.id`，并按 `type` 建立索引以支撑两跳/三跳过滤。
- 依据：递归 CTE 官方示例以邻接表（`graph(id, link, ...)`）为载体，并支持深度与环检测。[R2]

## 步骤 2 — 同库建表与扩展准备

- 在业务库所在的同一 PostgreSQL 16 实例中创建 `nodes` / `edges` 及索引。
- 若一期同时需要向量检索，执行 `CREATE EXTENSION vector;` 并在 `nodes` 上加 `vector` 列及 HNSW/IVFFlat 索引，使图与向量同库。
- 依据：pgvector 以扩展形式安装、与业务数据同库共存，支持 HNSW/IVFFlat 与余弦/L2/内积距离。[R3][R4]

## 步骤 3 — 存量数据一次性导入

- 从源数据导出为中间文件（如 CSV），用 `COPY` 或批量 `INSERT` 写入两表。
- 用单一事务包裹整批导入，任一失败即整体回滚，避免半导入状态。
- 依据：`pg_dump` 生成的转储内部一致，且可在单事务中恢复；批量装载与事务原子性为 PostgreSQL 标准能力。[R12][R3]

## 步骤 4 — 增量写入路径改造（同库同事务）

- 在业务写入路径中，把新增/变更的节点与关系在**同一事务**内写入 `nodes`/`edges`，与业务表变更共提交。
- 因图与业务同库，无需引入跨系统同步或双写对账；如存在只读副本需求，可用逻辑复制 publish/subscribe 下发变更。[R3][R15]
- 依据：PostgreSQL 原生 ACID；逻辑复制保证单一订阅内发布的事务一致性。[R3][R15]

## 步骤 5 — 两跳/三跳查询封装

- 编写参数化递归 CTE 查询，用 `depth <= 3` 限制跳数，用 `CYCLE` 子句防环，用 `SEARCH BREADTH FIRST` 稳定排序。
- 将查询封装为数据库视图或 SQL 函数，供应用统一调用，避免各调用方重复实现遍历逻辑。
- 依据：官方 `WITH RECURSIVE` 文档提供 `depth`、`path`、`CYCLE`、`SEARCH` 的完整写法与 `graph` 表示例。[R2]

## 步骤 6 — 备份与恢复演练

- 配置 `pg_dump` 定时逻辑备份（内部一致的 SQL 转储，可恢复到更新版本）。
- 开启 WAL 连续归档以启用 PITR，可恢复到基础备份之后任意时间点。
- 做一次恢复到独立验证库的演练，确认 `nodes`/`edges` 与图查询结果完整。
- 依据：SQL Dump 与 PITR 官方文档。[R12][R13]

## 步骤 7 — 一致性校验与灰度切换

- 对同一批虚构样例，逐条比对新旧查询路径返回的两跳/三跳结果，记录差异数。
- 先将读流量灰度切到新查询，观察无异常后全量切换；保留回滚开关至验证期结束。
- 依据：递归查询结果可用 `SEARCH`/`CYCLE` 稳定控制；同库事务一致性可由逻辑复制的事务保证辅助核对。[R2][R15]

## 步骤总览

| 步骤 | 名称 | 关键产出 |
|---|---|---|
| 1 | 资源盘点与图模型定稿 | 两表结构与索引方案 |
| 2 | 同库建表与扩展准备 | `nodes`/`edges` 表 + 可选 pgvector |
| 3 | 存量数据一次性导入 | 事务化批量装载 |
| 4 | 增量写入路径改造 | 同库同事务写入 |
| 5 | 两跳/三跳查询封装 | 视图 / SQL 函数 |
| 6 | 备份与恢复演练 | pg_dump + PITR 恢复报告 |
| 7 | 一致性校验与灰度切换 | 校验记录 + 灰度切换 |

共 7 步，满足"迁移草案 ≥ 5 步"的要求。
